# osouza.de dotfiles


## Installation
```
git clone https://github.com/osouza-de/dotfiles ~/dotfiles
cd ~/dotfiles
chmod +x install.sh
./install.sh
```

## One-line install
```
curl -fsSL https://raw.githubusercontent.com/osouza-de/dotfiles/refs/heads/master/install.sh | sed 's/\r$//' | sh
```
